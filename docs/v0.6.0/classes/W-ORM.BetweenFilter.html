      A filter that checks if a value is between two values.

      Type Parameters

      • T

        The type of the value to filter

      Parameters

      • lower: T | null

        The lower bound of the filter

      • upper: T | null

        The upper bound of the filter

      • lowerOpen: boolean = false

        Whether the lower bound is open

      • upperOpen: boolean = false

        Whether the upper bound is open

      Returns BetweenFilter<T>

      Example

      // Get all users with an age between 20 and 30
      const query = User.filter({ age: new BetweenFilter(20, 30) })
      // Get all users with an age between 20 and 30, excluding 20 and 30
      const query = User.filter({ age: new BetweenFilter(20, 30, true, true) })
